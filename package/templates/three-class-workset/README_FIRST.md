# Three-Class workset

このZIPのclassification canonical packageは `request/` です。最初に `request/REVIEW_INSTRUCTIONS.md` を読み、必要な場合だけ `request/` 内のS-taskおよびT-taskを処理してください。

`provenance/` はComment DBのlineage、元recordの順序・重複・出典を確認するための補助情報です。追加のclassification evidenceとして使用してはいけません。

`request/` にS-taskまたはT-taskのJSONが存在しないzero-handoff worksetでは、classification responseは不要です。既存pipelineが生成したworkspaceの状態をそのまま利用してください。
