# 状態コメントの文言改善案

作成日: 2026-10-23（JST）

状態: 文言の改善案を文書化済み。UIへの反映は未実施。

## 目的

ホーム画面の「状態コメント」で、選択期間の一次迷惑率に対する評価と、次に取る行動を把握できる状態にする。注意では対応候補からの対応の検討を促し、警告では対応候補からの対応を推奨する。

## 現状と改善点

現在の状態コメントは、選択期間の一次迷惑率から決まる評価区分に応じた固定文言である。前期間との比較や増減は判定に含まれていない。

- 目標達成時の「現在は落ち着いた状態です」は、選択期間の集計に基づく評価であることが伝わりにくい。
- 注意時は分析概要の確認、警告時は対応候補の確認を促しているが、対応の検討と対応の推奨という行動の違いを明示できていない。
- 共通の書き出し「一次迷惑率は {一次迷惑率の表示} で、」を独立した文にし、数値の説明と判定別の案内を読み取りやすくする。

## 文言の方針

- 評価対象を「選択期間」と明記する。
- 目標達成では目標値を満たしている事実を示し、現在のコメント欄の状態を断定しない。
- 目標未達では分析概要での内訳と推移の確認を促す。
- 注意では対応候補を確認し、フィルター設定やブロックによる対応を検討するよう促す。
- 警告では対応候補をもとに、フィルター設定やブロックによる対応を推奨する。
- 算出不可では数値を含む共通の書き出しを付けず、その理由を表示する。

## 表示文言案

### 共通の書き出し

算出可能な場合は、次の文章に判定別の文言を続ける。

> 選択期間の一次迷惑率は {一次迷惑率の表示} です。

`{一次迷惑率の表示}` は、既存の小数1桁の丸め値と丸め前の値の括弧書きを使用する。例えば一次迷惑率が4%の場合は `4.0% (4%)` とする。

### 判定別の文言

`p` は表示用に丸める前の一次迷惑率（%単位）、`N` は選択期間の対象観測数とする。条件は文書化時点の現行実装に基づく。

| 評価区分 | 判定キー | 条件 | 文言案 |
| --- | --- | --- | --- |
| 目標達成 | `goal_met` | `N > 0` かつ `0 ≤ p ≤ 2` | 目標の2%以下に収まっています。 |
| 目標未達 | `goal_unmet` | `N > 0` かつ `2 < p < 3.5` | 目標の2%を上回っています。分析概要で内訳と推移を確認してください。 |
| 注意 | `caution` | `N > 0` かつ `3.5 ≤ p < 4.5` | 注意水準です。対応候補を確認し、フィルター設定やブロックによる対応を検討してください。 |
| 警告 | `warning` | `N > 0` かつ `4.5 ≤ p` | 警告水準です。対応候補をもとに、フィルター設定やブロックによる対応を推奨します。 |
| 算出不可 | `unavailable` | `N = 0` | 選択期間に対象観測がないため、治安指数を算出できません。 |

### 表示例

注意（一次迷惑率4%）:

> 選択期間の一次迷惑率は 4.0% (4%) です。注意水準です。対応候補を確認し、フィルター設定やブロックによる対応を検討してください。

警告（一次迷惑率5%）:

> 選択期間の一次迷惑率は 5.0% (5%) です。警告水準です。対応候補をもとに、フィルター設定やブロックによる対応を推奨します。

算出不可:

> 選択期間に対象観測がないため、治安指数を算出できません。

## 修正対象と維持する仕様

主な修正対象は、[App.jsx](../../../../package/src/ui/App.jsx) の `statusComment()` にある共通の書き出しと判定別の文言である。ホーム画面の `DashboardScreen` がこの関数を使って状態コメントを表示している。

今回の改善案は状態コメントの文章を対象とする。評価区分・判定閾値・治安指数の算出方法、期間選択、部分観測の案内、カードの構成、読み込み中・読み込み失敗時の表示は維持する。

一次迷惑率は既存の `DirectNuisanceRate` による数値表示を維持する。判定は引き続き [public-order-index.js](../../../../package/src/ui/public-order-index.js) で丸め前の一次迷惑率から行う。

## 反映時の確認条件

- 算出可能な4区分では、共通の書き出しと該当区分の文言が表示される。
- 注意では対応の検討、警告では対応の推奨という違いが文言に反映される。
- 算出不可では、割合の文章を付けずに専用の文言だけが表示される。
- 期間の切り替え、既存の数値併記、丸め前の値による評価区分の判定が維持される。
- 長くなる注意・警告の文章が、PC幅とスマートフォン幅でカード内に収まる。
