# Work Task Sequence: 状態コメントの文言改善案の文書化

## Purpose

状態コメントの改善方針、判定別の文言案、修正対象、反映時の確認条件を参照でき、注意では対応の検討、警告では対応の推奨を促す違いが明確になっている。

## Task Sequence

- [x] 1. 既存の状態コメントの範囲で、AIエージェントが、表示文言と判定条件を確認する。
- [x] 2. 文言改善の要求整理の範囲で、AIエージェントが、会話で示された文言案と注意・警告の誘導方針を整理する。
- [x] 3. 改善案の文書化の範囲で、AIエージェントが、表示文言案と修正対象および反映時の確認条件を記録する。
- [x] 4. 文書の検証範囲で、AIエージェントが、会話内容と現行実装との整合性および参照先を確認する。
