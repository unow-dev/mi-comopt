# 治安指数 UI 実装設計

実装AIへ渡す正本は `IMPLEMENTATION_DESIGN.md` です。

## 読み方

- `不変仕様`: 実装で変更しない成果物の意味・維持契約
- `完了条件`: 実装完了時に確認する事実
- `確定設計`: 実装AIに再判断させない境界・契約
- `実装仮説`: 実コード上の事実に応じて変更可能な探索開始点

## 参照資料

- `prototype/`: 視覚参照。ダミーデータ・standalone実装は本番仕様ではない。
- `reference/source_snapshot/`: 設計時点の既存コード抜粋。実装先が更新されている場合は現行コードを調査する。

参照資料と正本が食い違う場合、成果物の意味は `IMPLEMENTATION_DESIGN.md` を優先する。実装仮説については現行コード上の具体的事実に応じて変更してよい。
