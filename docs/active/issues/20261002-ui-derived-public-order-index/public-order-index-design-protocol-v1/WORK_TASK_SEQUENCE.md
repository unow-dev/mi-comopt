# Work Task Sequence: 治安指数 UI

## Purpose

分析概要で、選択期間の観測情報をもとに治安指数と評価を確認でき、既存の分類内訳や日次推移とあわせてコメント欄の状態を把握できる。

## Task Sequence

- [ ] 1. 既存実装の範囲で、AIエージェントが、分析概要の集計・期間選択・表示構成・既存契約を確認する。
- [ ] 2. 仕様整理の範囲で、AIエージェントが、実装設計に定められた不変仕様・確定設計・完了条件を確認する。
- [ ] 3. 指標導出の範囲で、AIエージェントが、一次迷惑率・治安指数・評価および表示フォーマットを仕様に沿って実装する。
- [ ] 4. 分析概要表示の範囲で、AIエージェントが、選択期間に連動する観測情報・治安指数・分類内訳を統合する。
- [ ] 5. 既存表示契約の範囲で、AIエージェントが、日次推移・アプリシェル・固定ボトムナビ・safe-area対応を維持する。
- [ ] 6. 公開・永続契約の範囲で、AIエージェントが、治安指数を保存せず、DB・公開データ・ブラウザ永続状態の既存契約を維持する。
- [ ] 7. レスポンシブとアクセシビリティの範囲で、AIエージェントが、各画面幅での表示と期間切替の操作性を完了条件に沿って確認する。
- [ ] 8. 検証範囲で、AIエージェントが、計算境界・データ不足時の表示・期間連動・既存表示契約を完了条件に沿って確認する。
- [ ] 9. 作業結果の範囲で、AIエージェントが、変更内容と確認結果を記録する。

## Work Notes

- 正本は同じディレクトリの `IMPLEMENTATION_DESIGN.md`。参照資料やIssue本文と内容が異なる場合、成果物の意味は実装設計を優先する。
- `reference/source_snapshot/` は設計時点の抜粋であり、実装前に現行コードを確認する。
- 部分観測は観測情報欄に表示し、治安指数は観測できたデータから算出する。指数カードに「参考値」を付けず、少数観測による算出制限も設けない。
- 完了条件には、丸め前の値による評価判定、`N = 0` の算出不可表示、期間選択と日次系列の独立、指定画面幅での表示確認が含まれる。
