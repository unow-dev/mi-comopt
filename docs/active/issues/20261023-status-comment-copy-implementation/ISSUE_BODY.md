# Issue: 状態コメントに文言改善案を反映する

作成日: 2026-10-23（JST）

状態: 仕様と既存実装の確認済み。UIの修正・検証は未着手。

## 目的

ホーム画面の「状態コメント」に、選択期間の一次迷惑率に対する評価と次に取る行動が明確な文言が表示される状態にする。注意では対応候補からの対応の検討を促し、警告では対応候補からの対応を推奨する。

## 背景

現在の状態コメントは、目標達成時に「現在は落ち着いた状態です」と表示するため、選択期間の集計に基づく評価であることが伝わりにくい。また、注意では分析概要の確認、警告では対応候補の確認を促しており、対応の検討と対応の推奨という行動の違いが明示されていない。

この点を改善するため、[状態コメントの文言改善案](../20261023-status-comment-copy-improvement/ISSUE_BODY.md) に整理した文言をUIへ反映する。

## 修正範囲

対象は、ホーム画面の「状態コメント」に表示する共通の書き出しと、目標達成・目標未達・注意・警告・算出不可の各文言とする。

主な修正箇所は [App.jsx](../../../../package/src/ui/App.jsx) の `statusComment()` である。表示元は同ファイルの `DashboardScreen`、一次迷惑率の表示は `DirectNuisanceRate` を使用している。

## 反映する仕様

### 共通の書き出し

算出可能な4区分では、次の文章に判定別の文言を続ける。

> 選択期間の一次迷惑率は {一次迷惑率の表示} です。

`{一次迷惑率の表示}` は既存の小数1桁の丸め値と丸め前の値の括弧書きを使用する。例えば一次迷惑率が4%の場合は `4.0% (4%)` とする。

### 判定別の文言

| 評価区分 | 判定キー | 反映する文言 |
| --- | --- | --- |
| 目標達成 | `goal_met` | 目標の2%以下に収まっています。 |
| 目標未達 | `goal_unmet` | 目標の2%を上回っています。分析概要で内訳と推移を確認してください。 |
| 注意 | `caution` | 注意水準です。対応候補を確認し、フィルター設定やブロックによる対応を検討してください。 |
| 警告 | `warning` | 警告水準です。対応候補をもとに、フィルター設定やブロックによる対応を推奨します。 |
| 算出不可 | `unavailable` | 選択期間に対象観測がないため、治安指数を算出できません。 |

算出不可では共通の書き出しを付けず、専用の文言だけを表示する。

### 表示例

注意（一次迷惑率4%）:

> 選択期間の一次迷惑率は 4.0% (4%) です。注意水準です。対応候補を確認し、フィルター設定やブロックによる対応を検討してください。

警告（一次迷惑率5%）:

> 選択期間の一次迷惑率は 5.0% (5%) です。警告水準です。対応候補をもとに、フィルター設定やブロックによる対応を推奨します。

## 維持する仕様

- [public-order-index.js](../../../../package/src/ui/public-order-index.js) による一次迷惑率・治安指数・評価区分の算出方法を維持する。
- 目標達成は2%以下、目標未達は2%超かつ3.5%未満、注意は3.5%以上かつ4.5%未満、警告は4.5%以上とし、判定には丸め前の一次迷惑率を用いる。
- 対象観測数0件は算出不可とする。
- 一次迷惑率と治安指数の丸め値・丸め前の値の併記、数値の表示桁数、補足表示の文字サイズと読み上げ用ラベルを維持する。
- ホーム画面の7日・30日の期間選択、集計期間、対象観測数、部分観測の案内を維持する。
- 状態コメントのカード構成、読み込み中・読み込み失敗時の表示、対応候補への既存の導線を維持する。
- 公開データの取得・集計・候補生成・保存の仕組みを維持する。

## 完了条件

- 算出可能な4区分で、共通の書き出しと該当区分の文言が仕様どおりに表示される。
- 注意では「対応を検討してください」、警告では「対応を推奨します」と表示され、行動の強さが区別される。
- 算出不可では、割合を示す文章や数値を付けずに専用の文言だけが表示される。
- 7日・30日の切り替えに応じた評価と文言が一致する。
- 境界付近で表示用の丸め値が隣の区分に見える場合も、丸め前の値に基づく評価と文言の対応が維持される。
- 一次迷惑率の丸め値と括弧書きが、既存の表示形式で維持される。
- 注意・警告の長い文章が、PC幅・スマートフォン幅で欠けずに表示され、横方向にはみ出さない。
- 既存の [治安指数・一次迷惑率のテスト](../../../../package/tests/public-order-index.test.js) とUIの本番ビルドが成功する。
- 変更内容と実施した検証結果が作業記録に残されている。
