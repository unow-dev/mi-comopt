# 収集コメントのデータベース化

## 目的

収集したコメントをリポジトリ内で安全に蓄積し、フィルターキーワードの検討、コメント検索および傾向分析に継続して利用できる状態にする。

## 背景

現行のフィルターキーワード運用では、コメントの内容をもとに候補キーワードを検討する必要がある。コメントを一貫した形式で保存していない場合、過去の収集結果の再確認、キーワード候補の根拠確認および投稿・時期ごとの傾向把握が難しくなる。

収集コメントをデータベース化することで、コメント本文、取得時点、関連する投稿およびフィルター判定などを必要に応じて関連付け、後続の分析や運用改善に利用できるようにする。開発・個人運用の初期段階では、リポジトリ内にデータベースを配置する方針とする。

## 初期考察

- 実データを含むデータベースファイルはGit管理から除外し、スキーマ、マイグレーションおよび初期化手順をリポジトリで管理する。
- 保存対象は利用目的に必要な最小限に限定し、コメント本文、取得日時、投稿の識別情報、フィルター判定および検出キーワードを候補として検討する。
- ユーザー名、プロフィール情報など個人を特定しやすい情報は、保存の必要性、利用目的および保持期間を整理したうえで扱う。
- データベースの形式は、初期段階ではローカルで扱いやすいSQLiteを候補とし、複数利用者やサーバー運用が必要になった段階で外部データベースへの移行を検討する。
- コメントの取得元に適用される利用規約およびプライバシー上の要件を確認し、収集・保存・利用の範囲を定める。
