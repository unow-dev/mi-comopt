## 背景

`three-class-workset` は、既存の`HISTORY.json`を評価例として参照できる一方、Comment DBに保存されたラベリング済みコメントを自動的に評価例へ取り込まず、`ITEMS.json`から除外していない。そのため、同じコメントが既に3分類ラベルを持っていても、worksetの分類対象として再び提示され、既存評価の再ラベリングが発生し得る。

Comment DBのラベルは、同一コメントをキーに扱う。既存ラベルが複数存在して異なる場合は、3分類の意味上の優先順位である`direct_nuisance > reactive > normal`に従って、最も悪いラベルを採択する必要がある。採択済みの既存ラベルを評価例として提示し、同一コメントを再度分類対象にしないことで、既存評価との一貫性を保ち、新規コメントの分類に集中できる状態が必要である。

## 目的

Comment DBにラベリング済みのコメントを、完全一致するコメント文字列をキーとして3分類の評価例へ取り込み、`ITEMS.json`から除外する。同一コメントに異なるラベルがある場合は`direct_nuisance > reactive > normal`の順で最も悪いラベルに統一し、未ラベルかつ既存ラベルに一致しないコメントだけを新たな`three-class-workset`の分類対象として扱える状態を実現する。
