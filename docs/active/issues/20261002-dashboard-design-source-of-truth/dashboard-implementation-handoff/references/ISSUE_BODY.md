# ダッシュボードページのデザイン正本を整備する

## 目的

提示されたラフ案を起点に、ダッシュボードページの構成・表示内容・操作の意味を一貫して判断できるデザイン正本を定め、実装と今後の変更時に参照できる状態を実現する。

## 背景

ダッシュボードページのラフ案として、データ基準日と「今日のコメント欄」の見出し、治安指数と一次迷惑率・対象コメント数、マスコットによるコメント、確認が必要なフィルター候補・ブロック候補、各画面へのナビゲーションを一画面にまとめた案が提示された。ラフ案画像（[AIコメント分析ダッシュボード.png](./AIコメント分析ダッシュボード.png)）をIssueディレクトリに保持する。コメント欄の状態と次に確認すべき項目をすばやく把握する画面の方向性が示されている。

一方、ラフ案は静止画であり、「今日」やデータ基準日の扱い、各数値の意味と表示条件、マスコットのコメント内容、確認項目やナビゲーションの操作、画面幅に応じた構成などは一意に読み取れない。表示例の数値や文言を確定仕様と区別し、画面全体の情報の優先順位や状態ごとの見せ方を含めて判断できるデザイン正本が必要である。
