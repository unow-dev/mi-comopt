# Work Task Sequence: ダッシュボード実装handoff

## Purpose

現行のホームが仕様正本に沿ったダッシュボードとなり、データ状態・対応候補・画面間の期間共有を含む受け入れ条件を満たした状態にする。

## Task Sequence

- [x] 1. 仕様確認の範囲で、AIエージェントが、デザイン正本・受け入れ条件・実装ガイドから実装対象と変更しない条件を整理する。
- [x] 2. 既存実装の範囲で、AIエージェントが、ホーム・分析概要・データ取得・ナビゲーションの現在の挙動と変更箇所を確認する。
- [x] 3. ダッシュボード表示の範囲で、AIエージェントが、期間・集計値・状態コメント・対応候補を仕様どおりに表示する変更を行う。
- [x] 4. データ状態の範囲で、AIエージェントが、overviewの読み込み・正常・部分観測・算出不可・取得失敗を仕様どおりに扱う変更を行う。
- [x] 5. 期間と画面遷移の範囲で、AIエージェントが、ホームと分析概要の期間共有およびホームへの遷移時の正規化を実現する変更を行う。
- [x] 6. 操作とレイアウトの範囲で、AIエージェントが、候補画面への導線・レスポンシブ表示・アクセシビリティ要件を満たす変更を行う。
- [x] 7. 検証範囲で、AIエージェントまたはCIが、受け入れ条件と既存機能の非回帰を確認する。
- [x] 8. 作業結果の範囲で、AIエージェントが、実施内容・検証結果・残る制約を記録する。
