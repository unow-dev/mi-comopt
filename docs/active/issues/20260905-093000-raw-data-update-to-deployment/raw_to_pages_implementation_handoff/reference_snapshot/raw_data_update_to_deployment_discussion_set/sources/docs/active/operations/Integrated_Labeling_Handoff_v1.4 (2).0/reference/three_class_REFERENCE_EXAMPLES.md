# REFERENCE_EXAMPLES

以下は判定思想を固定するための例である。

## direct_nuisance

### 直接拒絶

```text
こっちみんな
```

投稿者への直接的な拒絶。
上流 nuisance。

### 直接嫌悪

```text
もうキツイって
```

投稿者/投稿への直接否定。
上流 nuisance。

### スパム

```text
[無関係な長文] フォローしろよ
```

一次的なフィルター対象。
direct_nuisance。

## reactive

### アンチへの攻撃

```text
アンチ潰したい
```

言葉自体は攻撃的でも対象はアンチ。
reactive。

### アンチへの反論

```text
なんでこんなに叩かれてるん?
```

批判状況への反応。
reactive。

### 擁護

```text
アンチなんて気にせず自分らしく生きてください
```

アンチが前提の応援。
reactive。

### コメント欄メタ

```text
アンチと擁護の戦場で草
```

投稿内容ではなくコメント欄の状況への反応。
reactive。

## normal

```text
今日も可愛い
```

アンチ文脈なし。
normal。

```text
応援しています
```

アンチ等を前提としていない通常応援。
normal。

## 要レビュー

### 混在

```text
アンチ＝嫉妬は無理ある。ぶりっ子は痛いって話
```

アンチ文脈がある一方、
投稿者への「ぶりっ子」「痛い」を自身の主張として述べている可能性がある。

P0 review。

### 引用と自身の評価の境界

```text
アンチが言いたいのは、本人が痛いってことでしょ
```

単なる説明か、実質的同意かを文脈で判定。
P0 review。

### 否定語を否定

```text
痛くもないしきつくもないので頑張って
```

「痛い」「きつい」が存在しても、それを否定している。
direct_nuisance にしてはいけない。
反応文脈が明白なら reactive、明白でなければ compatibility profile では normal のまま。
