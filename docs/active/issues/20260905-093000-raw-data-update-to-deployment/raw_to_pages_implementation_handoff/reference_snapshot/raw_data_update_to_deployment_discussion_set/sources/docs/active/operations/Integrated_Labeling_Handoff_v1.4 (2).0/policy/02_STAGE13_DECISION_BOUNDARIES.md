# Stage 13 判定境界 — 実績アンカー

この文書は公式仕様を置き換えない。前回確定ラベルで特に揺れやすかった境界を固定するための補助資料である。個別実例は `reference/golden_boundary_examples.json` を参照する。

## A. 否定語があるだけではnuisanceにしない

「きつい」「痛い」「鳥肌」「無理」「あざとい」「ぶりっ子」「計算」等は語だけで決めない。具体的作品・行為への評価、物理的痛み、肯定的用法、引用・擁護なら`normal`があり得る。

一方、人物・振る舞い全体への嫌悪、見世物化、羞恥付与として機能すれば`nuisance`。

## B. 年齢

- 単純質問・事実・肯定的年齢言及 → `normal`
- 「25歳が何してるの」「いい年して」「30手前で痛い」のように年齢を恥の根拠にする → `nuisance`
- 前回確定では「25歳が制服か」は`normal`、「25歳が制服😂」は`nuisance`。微妙な差は再解釈せず回帰アンカーとして保持する。

## C. 嘲笑・羞恥

「何を見せられてる」「一人でこれ撮ってると思うと笑う」「親に見せたら笑ってた」等は、表面上行為への反応でも、主機能が見世物化・羞恥付与なので`nuisance`。

## D. 動機決めつけ

「承認欲求の塊」「媚びてる」「炎上商法狙い」「全部計算」等、本人の内面・目的を悪意的に断定して人物価値を下げる場合は`nuisance`。

ただし「計算済みですか」の質問、「計算された可愛さ」の肯定、「〜に見えるのかもしれない」の弱い分析は`normal`実績がある。

## E. あざとい・ぶりっ子

否定的人物ラベルとして単独機能すれば`nuisance`。好意的・中立的・引用擁護なら`normal`。

## F. 性的対象化

通常の恋愛・好意（好き、付き合いたい、結婚したい等）は`normal`。AV、性的隠語、性行為要求、身体部位へのフェティッシュな執着、反復的性的含意は`nuisance`。

## G. コメント欄内の他者攻撃

投稿者を守る目的でも、アンチ・ファン・擁護者等を「キモい」「アホ」「勘違い野郎」等で人格攻撃すれば`nuisance`。通常の「悪口やめよう」「嫌なら見なければいい」は`normal`。

## H. 誘導・スパム

フォロー要求、DM誘導、無関係な長文コピペ誘導は`nuisance`。単に「フォローしてます」と報告する、返信を欲しがる通常交流は前回実績では`normal`。

## I. 反復handleが境界を変える

前回確定データでは、同一本文「誰か言ってやってくれ」が、反復否定handleでは`nuisance`、否定反復が弱い別handleでは`normal`になった。したがって、本文だけの辞書化は禁止。

同様に「あいたた」系の短文は、単体では`normal`確定例がある一方、反復否定handleでは`nuisance`確定例がある。
