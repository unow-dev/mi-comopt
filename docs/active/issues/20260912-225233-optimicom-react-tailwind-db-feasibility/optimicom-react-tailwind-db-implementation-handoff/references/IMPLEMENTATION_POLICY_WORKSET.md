# Implementation Policy Workset: `optimicom-react-tailwind`

## Purpose

本書は、`optimicom-react-tailwind` を実装する際の対象データ、分類、集計、更新、状態管理、DB変更および段階導入方針を、人間が決定・記録するためのワークセットである。

本書の決定欄が埋まり、必須決定が承認されるまで、実装者は未決事項を独自判断で確定しない。実現可否の根拠は [FEASIBILITY_REPORT.md](./FEASIBILITY_REPORT.md) を参照する。

## How to Use

1. 各決定項目の選択肢を比較し、`決定`、`理由`、`実装への影響`を記入する。
2. 選択肢にない方針を採用する場合は、`その他`に具体的な条件を記入する。
3. `必須`の決定が未記入の間は、関連する実装タスクを着手可能としない。
4. 決定後に実装方針、DB変更、受入条件および非対象範囲を確定する。
5. 方針を変更した場合は、既存の決定を上書きせず、末尾の変更履歴に理由と影響を記録する。

## Confirmed Baseline

以下は決定事項ではなく、調査で確認された前提である。

- 対象UIはホーム、集計・現状・推移、コメント一覧、フィルターキーワード候補、ブロックアカウント候補の5画面である。
- 対象UIは `src/data.js` のサンプルデータ、固定チャート、固定文言、画面内React stateを使用し、DB取得・集計・永続化を行っていない。
- 現行DBは user_version 7。rich snapshot 8件、comment-batch 1件、コメント観測27,299件、3分類ラベル24,622件、keyword candidate publication 1件を保持する。
- DBラベルは `direct_nuisance` 731件、`reactive` 1,339件、`normal` 22,552件の3分類である。
- 6分類（肯定的・中庸的・批判的・対批判・迷惑・対迷惑）への可逆な対応表は存在しない。
- DBの最終投稿日は2026-09-05であり、調査日2026-09-13時点の24時間・7日間データは存在しない。
- DBから現行ポリシーで再集計した空でないハンドルのブロック候補は60件・direct_nuisance 224件。配置済みアーティファクトは54件・202件である。
- 現行のキーワード公開JSONはDB上86候補だが、配置済み成果物の公開履歴・hash・再構成検証には不一致がある。
