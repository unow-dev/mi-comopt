# TikTokコメント 選別基準仕様 — Stage 13

## 1. 目的
TikTokコメントを `normal` / `nuisance` の2値で分類する。`nuisance` は、投稿者がキーワードフィルター等で非表示候補にしたい攻撃的・侮蔑的・性的・嫌がらせ的・スパム的な本文表現を対象とする。

Stage 13では単純なNGワード判定ではなく、コメントが実際に果たしている機能を重視する。

## 2. 基本原則
原則 `normal`:
- 肯定、応援、質問、雑談
- 通常の恋愛的・好意的表現
- 投稿内容、動画、作品、演出、服装、発言、特定行為への通常の批判
- 投稿者への攻撃を批判・報告・反論・擁護するコメント
- 単なる意見の不一致

否定的であること自体を `nuisance` の理由にはしない。

## 3. `nuisance` の基本対象
以下を `nuisance` とする。
- 直接的な侮辱・人格攻撃
- 嘲笑・羞恥付与
- 人物価値の毀損
- 容姿・身体・年齢・能力等を使った侮辱
- 性的対象化・フェティッシュな品評や要求
- 有害な決めつけ・悪意的な動機推測
- 比較による侮辱
- 排除要求
- 脅迫、暴力、死を向ける敵意
- コメント欄内の他者への人格攻撃
- 明白なスパム、誘導、自己宣伝

## 4. 行為批判と人物攻撃の区別
`normal` 寄り:
- この編集は微妙
- この演出は好きではない
- この服は似合わないと思う
- この部分はきつい

`nuisance` 寄り:
- 人物そのものを低く評価する
- 年齢や容姿を使って恥を与える
- 「一人でこれ撮ってると思うと笑う」等の冷笑
- 「親にこの動画見せてみて」等の羞恥付与
- 「何してるのw」「何を見せられてるん」等の見世物化

表面上は行為批判でも、主機能が嘲笑・羞恥付与なら `nuisance` とする。

## 5. 短い嫌悪・侮蔑
Stage 13では、以下のような短文を比較的厳しく判定する。
- いたい
- おえ / おえっ
- こわい
- 痛すぎる
- 無理
- きつい
- あざとい

人物・振る舞い全体への嫌悪・嘲笑として読む方が自然なら `nuisance`。具体的な作品・演出への通常批評として読む方が自然なら `normal`。

## 6. 年齢・容姿・身体・能力を利用した攻撃
以下は `nuisance`。
- 25歳にもなってこれはきつい
- 23でこれは痛い
- その歳で何やってるの
- 見た目でカバーしきれてない

単純な年齢質問（「何歳ですか？」「25歳なの？」）は `normal`。

## 7. 有害な決めつけ・動機攻撃
本人の内面や目的を悪意的に断定・推測し、人物価値を下げる場合は `nuisance`。
例:
- 炎上商法でしょ
- 承認欲求の塊
- 媚びてるだけ
- 全部計算してやってる
- 自分が可愛いと思ってるからやってる
- 都合の悪いコメントだけ無視してる

攻撃性の弱い単なる疑問・分析は `normal` に残し得る。

## 8. 「ぶりっ子」「あざとい」等
否定的な人物ラベルとして使われている場合は `nuisance`。
好意的・中立的な用法（「あざとくて可愛い」「このあざとさ好き」）は `normal`。

## 9. 性的対象化
通常の好意・恋愛表現は `normal`。
例: 可愛い、美人、好き、付き合いたい、デートしたい、彼女にしたい。

投稿者を性的消費物として扱う場合は `nuisance`。
例:
- AVに行ったら売れそう
- 今日はこれでいいや
- おかずありがとうございます
- えっちしたい
- セフレならいい
- 身体部位への性的執着
- 脇、唾液、体臭等へのフェティッシュな言及
- 性的行為を暗示する要求
- 「咥える」等への性的な執着

直接的な性語がなくても、一般的な性的隠語・文脈が明白なら `nuisance`。

## 10. 排除要求
投稿者に活動・投稿をやめさせることを目的とする表現は `nuisance`。
例: 「もうやめろ」「TikTokやめた方がいい」「そろそろやめよう」。
作品改善についての通常提案は `normal`。

## 11. 比較による侮辱
誰かと比較して投稿者または他人の価値を落とす表現は `nuisance`。
単なる類似比較や好意的比較は `normal`。

## 12. 他コメント投稿者・ファンへの攻撃
Stage 13では、投稿者本人だけでなくコメント欄内の他者への明確な人格攻撃も `nuisance` とする。方向は問わない。

例:
- 囲いが一番キツい
- 擁護してる奴らアホ
- アンチしてる奴頭おかしい
- バカが多い
- 現実では誰にも相手にされない
- クソガキ
- 醜い

通常の反論・擁護（「悪口を書く必要はない」「嫌なら見なければいい」等）は `normal`。

## 13. 同一ユーザーによる反復的な否定
同一 `handle` から否定・嘲笑・嫌悪コメントが2件以上確認された場合、そのユーザーを作業上の「反復否定ユーザー」とみなす。

そのユーザーの否定コメントについては `nuisance` 判定を強める。単発なら `normal` と判断可能だった軽度の否定でも、反復的嫌がらせの一部として自然なら `nuisance` とする。

ただし、同一ユーザーの肯定・質問・雑談・中立コメントまで一括で `nuisance` にしてはならない。コメント単位の判定を維持する。

`postedDate` は必要に応じて反復の時系列確認に利用できるが、投稿間隔や投稿頻度だけを理由に `nuisance` としてはならない。

## 14. 反復的な性的対象化
同一 `handle` が複数回、身体・性的含意・フェティッシュなコメントを投稿している場合、単発では曖昧な性的表現も `nuisance` 側へ判定を強める。

## 15. スパム・誘導
以下は `nuisance`。
- 自己宣伝
- フォロー要求
- DM誘導
- 外部サイト誘導
- 不自然な営業
- 無関係な勧誘
- 同一・類似内容のコピペスパム

単なる同一ユーザーの連投だけではスパムとしない。

## 16. 引用・報告・擁護
攻撃語が含まれていても、引用して批判・報告・反論・擁護しているだけなら、その引用部分だけを理由に `nuisance` にしない。

ただし反論の中で別の人物へ新たな侮辱を行っている場合は `nuisance`。

## 17. 判定優先順位
迷った場合は以下の順に確認する。
1. 脅迫・暴力・明確な侮辱
2. 性的対象化
3. 人物価値の毀損
4. 嘲笑・羞恥付与
5. 有害な動機決めつけ
6. 排除要求
7. 他コメント投稿者への人格攻撃
8. 同一ユーザーによる反復的否定
9. 単なる作品・行為への批判か
10. 通常の好意・質問・雑談か

1〜8が強く成立する場合は `nuisance`。9〜10に留まる場合は `normal`。

## 18. Stage 13の性格
Stage 13は初期基準より明確に厳格である。主要な拡張点は以下。
1. 同一ユーザーによる複数回の否定を判定材料として利用する。
2. 投稿者本人だけでなく、ファン・アンチ等の他コメント投稿者への人格攻撃も `nuisance` とする。
3. 短い嫌悪・嘲笑表現について、人物への侮蔑として読む範囲を広く取る。

目的は、通常の批判・好意・質問・雑談を残しながら、侮辱、嘲笑、羞恥付与、性的対象化、有害な決めつけ、排除、反復的嫌がらせ、コメント欄内の対人攻撃を広めに非表示候補化することである。
