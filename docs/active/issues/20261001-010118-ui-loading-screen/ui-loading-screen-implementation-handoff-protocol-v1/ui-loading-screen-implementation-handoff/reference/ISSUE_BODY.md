# Issue: UIにデザイン正本準拠のローディング画面を実装する

## 目的

UIのデータ読み込み中にデザイン正本に基づくローディング画面が表示され、利用者が読み込み状態を把握できるとともに、アプリのブランド表現と一貫した体験を得られる状態にする。

## 背景

現在のUIでは、公開データのrelease rootや各画面のデータを読み込む間、カード内に読み込み中の文言を表示している。読み込み状態は伝わるものの、専用の視覚表現はなく、待機中の画面にアプリのブランドや一貫したデザインが反映されていない。

本Issueで実装するローディング画面のデザイン正本は、Issueディレクトリ内に保持する `comment-loading-design-master-reviewed.zip` とする。同梱資料には、エンブレムや背景装飾、読み込み中の文字表示を組み合わせた画面デザインが定義されている。現在の読み込み待機表示を、この正本に沿った体験へ整える必要がある。
